# AthletiX 🏟️

AthletiX is a modern multi-sport intelligence platform designed to bring live sports data, teams, players, standings, schedules, and comparisons into one unified experience.

Built with a focus on clean architecture, responsive design, and a premium sports-tech user experience, AthletiX transforms complex sports information into an intuitive and engaging platform.

## ✨ Features

### Live Sports Experience

* View live games and scores
* Track game status and important match information
* Browse games by sport and league

### Teams

* Explore teams across multiple leagues
* View team profiles and details
* Access schedules, standings, and team information

### Players

* Search and discover players
* View player profiles and statistics
* Analyze player performance data

### Comparisons

* Compare teams and players
* View side-by-side statistics
* Analyze performance differences

### User Experience

* Responsive design across desktop, tablet, and mobile
* Modern sports-focused interface
* Fast data loading with optimized API handling

# 🚀 Getting Started

## Prerequisites

Make sure you have:

* Node.js installed
* npm installed

---

## Clone Repository

```bash
git clone https://github.com/zuhairtahir-oss/AthletiX.git

cd AthletiX
```

---

# Frontend Setup

```bash
cd frontend

npm install

npm run dev
```

The frontend will start locally through Vite.

---

# Backend Setup

Open another terminal:

```bash
cd backend

npm install

npm run dev
```

The backend API will start locally.
